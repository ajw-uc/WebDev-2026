# Sesi 3.C. Bootstrap
Membuat tampilan lebih modern dan responsive dengan menggunakan Bootstrap CSS framework.

## File terkait
- `public/css/style.css` - custom css
- `resources/views/components/form/group.blade.php` - komponen form group untuk memberikan spacing antar inputan
- `resources/views/components/post-card.blade.php` - komponen untuk menampilkan card post
- `resources/views/components/post-comment.blade.php` - komponen untuk menampilkan comment post
- `resources/views/layout/default.blade.php` - layout default
- `resources/views/home.blade.php` - ubah ke versi bootstrap
- `resources/views/post/show.blade.php` - ubah ke versi bootstrap
- `resources/views/post/form.blade.php` - ubah ke versi bootstrap
- `resources/views/user/edit.blade.php` - form untuk edit profil
- `resources/views/user/index.blade.php` - menambahkan link untuk edit profile dan create post
