# Sesi 8.B. Upload
Mengupload gambar di post dan menampilkannya.

## File terkait
- `app/Http/Controllers/PostController.php` - Fungsi untuk upload dan delete file
- `public/css/style.css` - Tambah style image
- `resources/views/components/post-card.blade.php` - Menampilkan gambar dan popup preview
- `resources/views/post/_form.blade.php` - Tambah keterangan input gambar dan tampilkan gambar jika ada
- `resources/views/post/create.blade.php` - Tambah form multipart
- `resources/views/post/edit.blade.php` - Tambah form multipart

## Referensi
- Upload: https://laravel.com/docs/13.x/filesystem#file-uploads
- Delete: https://laravel.com/docs/13.x/filesystem#file-deletion
